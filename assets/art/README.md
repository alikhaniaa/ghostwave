# Art textures (not included)

`src/main.cpp` loads these files at startup:

| File | Used for |
| --- | --- |
| `etched-basalt.png` | Tileable terrain material (square, repeats on rocks, roots and floor) |
| `knifefish.png` | Side-view fish sprite with a transparent background, head facing right |
| `signal-title.png` | Title-screen background, 16:10 |

They are not distributed with this repository. Place your own PNG files with
these names here to use them. If any of them is missing, the game shows an
"ART OR SHADER MISSING" banner.
